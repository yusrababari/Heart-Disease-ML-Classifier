# Heart Disease ML Classifier

HeartScope — a heart disease risk predictor with a purple-themed React UI and a FastAPI + LightGBM backend. Deploys as a **single Vercel project**: the Vite frontend is served as static files and the FastAPI app runs as a Python serverless function.

## Features

- Predicts heart disease risk from clinical, demographic and lifestyle factors
- New factors: **weight**, **smoking** and **diabetes** (synthetic, generated by `build_model.py`)
- **View All Graphs** button regenerates all 19 notebook visualizations live from the training data
- Deep-purple, glassmorphism UI

## Local development

Backend (port 8000):

```bash
venv/bin/python -m uvicorn main:app --port 8000
```

Frontend (Vite dev server proxies `/api` → `http://127.0.0.1:8000`):

```bash
npm install
npm run dev
```

Retrain the model after changing data:

```bash
venv/bin/python build_model.py
```

## Deploying to Vercel

Both the frontend and backend deploy together in one project.

1. Push this repo to GitHub.
2. In Vercel, **Import Project** → select the repo.
3. The framework preset auto-detects **Vite**; the `api/` directory is picked up as the Python serverless function automatically.
4. Click **Deploy**. Nothing else to configure — `vercel.json` wires it all up.

What `vercel.json` does:

- Rewrites `/api/*` to the FastAPI function (`api/index.py`)
- Falls back all other routes to the SPA (`/index.html`)
- Bundles the model + data files with the function and raises the function timeout to 60 s (needed for the live graphs endpoint)

The frontend calls the API at the relative path `/api`, so it works on the same origin in production. To point at a different API, set `VITE_API_URL` at build time (e.g. `VITE_API_URL=https://my-api.example.com`).

> Note: `/api/graphs` imports heavy ML/plotting libraries, so expect a slow first (cold) request. If your plan's function timeout is tighter, consider pre-generating the charts.

## Structure

```
api/index.py          Vercel serverless entry point (FastAPI handler)
main.py               FastAPI app — /api/features, /api/predict, /api/graphs
graphs.py             Regenerates all notebook charts (purple theme)
build_model.py        Enriches data + retrains LightGBM, exports model & features
src/                  React UI (Vite)
public/               Static assets
data/                 train.csv / test.csv
heart_model.pkl       Trained LightGBM model
feature_names.json    Model input features
vercel.json           Vercel routing & function config
```
